Developer from the Netherlands building audio software and sim-racing tools.

- 🎛️ Building **[Hardwave Studios](https://hardwavestudios.com)** — audio tools for harder-styles producers
- 🏎️ Building **[MyRacingData](https://myracingdata.com)** — sim-racing telemetry & league platform
- 🦀 Mostly working in **Rust, TypeScript, and Python**
